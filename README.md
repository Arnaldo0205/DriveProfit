# DriveProfit

DriveProfit is a personal software engineering project designed to help gig delivery drivers track their earnings, expenses, mileage, and profitability.

## Problem Statement

Delivery drivers often focus on gross earnings without considering fuel expenses, mileage, and vehicle operating costs.

DriveProfit aims to help drivers better understand their financial performance.

## Planned Features

- Track daily delivery earnings.
- Record working hours.
- Track mileage and fuel expenses.
- Calculate profit after recorded expenses.
- Calculate hourly earnings.
- Calculate earnings per mile.
- Store delivery session history.
- Display weekly and monthly statistics.
